# Release Notes - Horizon Launcher v1.0.0

## Дата релиза: 2026-01-19

## Что нового

### UI/UX Обновления

- ✅ **Dark Liquid Glass Design** - Полностью обновленный дизайн согласно tech.md
- ✅ **Цветовая палитра** - Точные цвета из спецификации:
  - Background: `#14141e` (Deep Navy)
  - Surface: `rgba(30, 30, 45, 0.6)` + blur 50px
  - Primary Gradient: `#667eea` → `#764ba2` (Violet Glow)
  - Accent: `#00f2fe` (Cyber Cyan)
- ✅ **Role Badges** - Градиенты для всех ролей (Owner, Curator, Admin, и т.д.)
- ✅ **Shimmering эффекты** - Анимация для Owner/Curator ролей
- ✅ **Pulse Glow** - Пульсирующее свечение для кнопок "Log In" и "PLAY"
- ✅ **Glass Panels** - Панели с эффектом стекла и backdrop blur
- ✅ **2FA Glass Boxes** - 6 отдельных glass boxes для ввода кода 2FA

### Функциональность

- ✅ **Авторизация** - Регистрация, вход, Telegram 2FA, восстановление пароля
- ✅ **Магазин** - Покупка косметики, отображение баланса
- ✅ **Форум** - Категории, темы, сообщения, лайки
- ✅ **Запуск игры** - Автоматическая загрузка Java Runtime, версий, ассетов
- ✅ **Anti-Inject защита** - Сканирование процессов на наличие читов
- ✅ **HWID защита** - Привязка аккаунтов к устройству

### Технические улучшения

- ✅ **Maven Shade Plugin** - Сборка исполняемого JAR со всеми зависимостями
- ✅ **Обновленные зависимости** - JavaFX 21.0.2, OkHttp 4.12.0, Gson 2.10.1
- ✅ **Улучшенная обработка ошибок** - Детальные сообщения об ошибках
- ✅ **Логирование** - SLF4J + Logback для детального логирования

## Известные проблемы

- Предупреждение о deprecated API в `StoreController.java` (не критично)
- Предупреждения Maven Shade Plugin о module-info.class (не критично, не влияет на работу)

## Требования

- Java 21+
- API сервер должен быть запущен на `http://localhost:3000` (или настроен в `config.properties`)

## Установка

1. Скачайте `horizon-launcher-1.0.0.jar`
2. Убедитесь, что установлена Java 21+
3. Запустите: `java -jar horizon-launcher-1.0.0.jar`

## Конфигурация

Перед первым запуском настройте `config.properties`:
- `api.server.url` - URL API сервера
- `telegram.bot.url` - Ссылка на Telegram бота

## Поддержка

При возникновении проблем:
- Проверьте логи в `logs/` директории
- Убедитесь, что API сервер запущен
- Проверьте конфигурацию в `config.properties`

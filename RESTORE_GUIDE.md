## Как восстановить Java лаунчер?

### Вариант 1: Восстановление из Git (если файлы были в коммитах)

```bash
# Посмотреть все коммиты где были файлы
git log --all --full-history -- launcher-java/src/main/java/com/horizon/launcher/LauncherApplication.java

# Восстановить файл из конкретного коммита
git checkout <commit-hash> -- launcher-java/src/main/java/com/horizon/launcher/LauncherApplication.java
```

### Вариант 2: Восстановление из скомпилированных классов

В `target/classes` есть скомпилированные `.class` файлы. Можно попробовать декомпилировать их обратно в Java код с помощью:
- JD-GUI
- CFR
- Procyon

### Вариант 3: Пересоздание (рекомендуется)

Если файлы не удается восстановить, можно пересоздать структуру проекта на основе скомпилированных классов и восстановленного API.

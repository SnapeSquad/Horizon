# Подробное руководство по интеграции Figma дизайна

## Шаг 1: Подготовка дизайна в Figma

### 1.1 Организация файла
- Убедитесь, что все компоненты названы понятно
- Используйте стили для цветов, типографики и эффектов
- Группируйте связанные элементы

### 1.2 Создание дизайн-системы
1. **Цвета**: Создайте Color Styles для всех используемых цветов
2. **Типографика**: Создайте Text Styles для заголовков, текста, кнопок
3. **Эффекты**: Создайте Effect Styles для теней, размытий

## Шаг 2: Экспорт ресурсов

### 2.1 Экспорт иконок
```bash
# Рекомендуемый формат: SVG для векторных иконок
# Размещение: design/assets/icons/
```

**В Figma:**
1. Выберите иконку
2. Правый клик → Export
3. Выберите формат SVG
4. Сохраните в `design/assets/icons/`

### 2.2 Экспорт изображений
```bash
# Форматы: PNG @2x для растровых изображений
# Размещение: design/assets/images/
```

### 2.3 Экспорт шрифтов
1. Определите используемые шрифты в дизайне
2. Скачайте файлы шрифтов (.ttf, .woff2)
3. Разместите в `design/assets/fonts/`

## Шаг 3: Извлечение токенов

### 3.1 Цвета
1. Откройте панель Design → Colors в Figma
2. Для каждого цвета запишите:
   - HEX значение
   - RGB/RGBA для прозрачности
   - Назначение (primary, secondary, etc.)
3. Добавьте в `design/tokens/colors.json`

**Пример:**
```json
{
  "primary": {
    "main": "#667eea",
    "rgba": "rgba(102, 126, 234, 1)"
  }
}
```

### 3.2 Типографика
1. Выберите текстовые элементы в Figma
2. Запишите:
   - Размер шрифта
   - Вес (font-weight)
   - Межстрочный интервал (line-height)
   - Семейство шрифта
3. Добавьте в `design/tokens/typography.json`

### 3.3 Отступы и размеры
1. Используйте инструмент измерения в Figma
2. Запишите:
   - Отступы между элементами
   - Размеры компонентов
   - Радиусы скругления
3. Добавьте в `design/tokens/spacing.json`

## Шаг 4: Применение к проекту

### 4.1 Для Electron версии (index.html)

#### Подключение стилей
1. Создайте файл `design/styles/electron/main.css`
2. Подключите в `index.html`:
```html
<link rel="stylesheet" href="design/styles/electron/main.css">
```

#### Использование токенов
```css
/* Импортируйте токены из JSON или используйте CSS переменные */
:root {
  --color-primary: #667eea;
  --spacing-md: 16px;
  --font-size-base: 14px;
}
```

### 4.2 Для JavaFX версии (launcher-java)

#### Применение стилей
1. Создайте файл `design/styles/javafx/figma-theme.css`
2. Скопируйте в `launcher-java/src/main/resources/styles/`
3. Подключите в Java коде:
```java
scene.getStylesheets().add(
    getClass().getResource("/styles/figma-theme.css").toExternalForm()
);
```

#### Конвертация CSS для JavaFX
JavaFX использует свой синтаксис CSS:
- `background-color` → `-fx-background-color`
- `border-radius` → `-fx-background-radius`
- `padding` → `-fx-padding`

## Шаг 5: Автоматизация (опционально)

### Использование Figma API

1. Получите токен доступа:
   - Figma → Settings → Account → Personal Access Tokens

2. Используйте скрипт для экспорта:
```javascript
// scripts/figma-export.js
const figmaApi = require('figma-api');
// ... код экспорта
```

### Использование плагинов Figma

**Figma Tokens:**
1. Установите плагин "Figma Tokens"
2. Настройте экспорт токенов
3. Экспортируйте в JSON формат

**Figma to Code:**
1. Установите плагин "Figma to Code"
2. Выберите компонент
3. Получите готовый CSS код

   # Обновите файлы в design/tokens/

   # Обновите файлы в design/styles/

## Часто задаваемые вопросы

**Q: Как экспортировать градиенты?**
A: Градиенты нужно записывать вручную в формате CSS linear-gradient()

**Q: Как работать с эффектами размытия?**
A: Запишите значения blur в spacing.json и используйте backdrop-filter в CSS

**Q: Можно ли автоматизировать весь процесс?**
A: Частично - используйте Figma API и скрипты для экспорта, но некоторые вещи требуют ручной настройки

# Типографика

## Семейства шрифтов

### Primary Font
```
-apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Segoe UI', sans-serif
```

**Использование:**
- Основной текст интерфейса
- Кнопки
- Заголовки

### Monospace Font
```
'SF Mono', 'Monaco', 'Consolas', monospace
```

**Использование:**
- Код
- Техническая информация
- Логи

## Размеры шрифтов

| Название | Размер | Использование |
|----------|--------|---------------|
| XS | 12px | Подписи, метки |
| SM | 13px | Мелкий текст |
| Base | 14px | Основной текст |
| MD | 16px | Кнопки, подзаголовки |
| LG | 18px | Средние заголовки |
| XL | 20px | Заголовки разделов |
| 2XL | 22px | Большие заголовки |
| 3XL | 24px | Очень большие заголовки |
| 4XL | 32px | Главные заголовки |

## Насыщенность шрифтов

- **Normal**: 400 - Обычный текст
- **Medium**: 500 - Средняя насыщенность
- **Semibold**: 600 - Полужирный (кнопки, акценты)
- **Bold**: 700 - Жирный (заголовки)

## Межстрочные интервалы

- **Tight**: 1.2 - Для заголовков
- **Normal**: 1.5 - Для основного текста
- **Relaxed**: 1.75 - Для длинных текстов

## Текстовые стили

### Title (Заголовок)
```css
font-size: 32px;
font-weight: 700;
line-height: 1.2;
color: #ffffff;
```

### Subtitle (Подзаголовок)
```css
font-size: 16px;
font-weight: 400;
line-height: 1.5;
color: rgba(255, 255, 255, 0.9);
```

### Body (Основной текст)
```css
font-size: 14px;
font-weight: 400;
line-height: 1.5;
color: rgba(255, 255, 255, 0.8);
```

### Button (Кнопка)
```css
font-size: 16px;
font-weight: 600;
line-height: 1.2;
color: #ffffff;
```

### Caption (Подпись)
```css
font-size: 12px;
font-weight: 400;
line-height: 1.5;
color: rgba(255, 255, 255, 0.6);
```

## Применение в проекте

### Electron (CSS)
```css
.title {
  font-size: 32px;
  font-weight: 700;
  line-height: 1.2;
}
```

### JavaFX
```css
.title {
    -fx-font-size: 32px;
    -fx-font-weight: 700;
}
```

## Рекомендации

1. **Заголовки**: Используйте жирный шрифт (700) для акцента
2. **Текст**: Используйте нормальный вес (400) для читаемости
3. **Кнопки**: Используйте полужирный (600) для видимости
4. **Межстрочный интервал**: Используйте 1.5 для основного текста

# Цветовая палитра

## Основные цвета

### Primary (Основной)
- **Main**: `#667eea` - Основной цвет бренда
- **Light**: `#764ba2` - Светлый вариант
- **Dark**: `#4c63d2` - Темный вариант

**Использование:**
- Основные кнопки
- Акцентные элементы
- Интерактивные элементы

### Secondary (Вторичный)
- **Main**: `#f093fb` - Вторичный цвет
- **Light**: `#f5b3ff` - Светлый вариант
- **Dark**: `#e673f0` - Темный вариант

**Использование:**
- Вторичные кнопки
- Дополнительные акценты

## Фоновые цвета

### Glass Effect (Эффект стекла)
- **Primary**: `rgba(255, 255, 255, 0.1)` - Основной стеклянный фон
- **Secondary**: `rgba(255, 255, 255, 0.15)` - Вторичный фон
- **Glass**: `rgba(255, 255, 255, 0.12)` - Карточки и панели

**Использование:**
- Фоны карточек
- Панели навигации
- Модальные окна

## Цвета текста

- **Primary**: `#ffffff` - Основной текст
- **Secondary**: `rgba(255, 255, 255, 0.9)` - Вторичный текст
- **Tertiary**: `rgba(255, 255, 255, 0.8)` - Третичный текст
- **Disabled**: `rgba(255, 255, 255, 0.6)` - Неактивный текст

## Границы

- **Default**: `rgba(255, 255, 255, 0.2)` - Обычная граница
- **Hover**: `rgba(255, 255, 255, 0.3)` - При наведении
- **Focus**: `rgba(102, 126, 234, 0.8)` - При фокусе

## Акцентные цвета

- **Success**: `#2ecc71` - Успешные действия
- **Error**: `#e74c3c` - Ошибки
- **Warning**: `#f39c12` - Предупреждения
- **Info**: `#3498db` - Информация

## Градиенты

### Primary Gradient
```css
linear-gradient(to right, #667eea 0%, #764ba2 100%)
```

### Background Gradient
```css
linear-gradient(135deg, #667eea 0%, #764ba2 50%, #f093fb 100%)
```

## Применение в проекте

### Electron (CSS)
```css
:root {
  --color-primary: #667eea;
  --color-primary-light: #764ba2;
}
```

### JavaFX
```css
.btn-primary {
    -fx-background-color: linear-gradient(to right, #667eea 0%, #764ba2 100%);
}
```

# Карта компонентов Figma → JavaFX

## Изученные страницы из Figma:

### ✅ AuthPage
- Переключатель Лицензия/Пиратка ✅
- Градиентный заголовок
- Поля ввода с иконками
- Кнопка с градиентом и свечением

### 📊 DashboardPage
**Структура:**
- Sidebar слева (80px)
- Header сверху (80px):
  - Баланс с иконкой монеты
  - Уведомления с красной точкой
  - Профиль с аватаром
- Слайдер новостей (400px высота):
  - Полноэкранные изображения
  - Градиентный оверлей
  - Кнопки навигации
  - Точки-индикаторы
- Карточки серверов:
  - Название + режим
  - Онлайн статус (зеленая точка)
  - Прогресс онлайна
  - Кнопка "Играть" с градиентом

### 🛍️ ShopPage
- Карточки 3 колонки
- Бейджи "Популярное" (золотой градиент)
- Иконки товаров (эмодзи)
- Цена фиолетовым
- Кнопка "Купить" с иконкой корзины

### 👕 WardrobePage
- 3D модель слева (вращение)
- Справа: вкладки (Одежда/Аксессуары/Питомцы)
- Карточки предметов с редкостью:
  - common: #9CA3AF
  - rare: #3B82F6
  - epic: #A855F7
  - legendary: #F59E0B
- Замок на недоступных
- Галочка на экипированных

## Цвета из Figma:

```
Фон: #0F0F13
Акцент: #7C4DFF
Градиент акцента: #7C4DFF → #B794F6
Текст: #E0E0E0
Вторичный текст: #9CA3AF
Карточка: rgba(255, 255, 255, 0.05)
Граница: rgba(124, 77, 255, 0.2)
```

## Эффекты:

- backdrop-filter: blur(20px) - НЕ поддерживается JavaFX
- Используем: -fx-effect: dropshadow
- Градиенты: linear-gradient работают
- Анимации: FadeTransition, ScaleTransition

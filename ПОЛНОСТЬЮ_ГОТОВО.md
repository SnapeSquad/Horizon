## 🚀 **КАК ЗАПУСТИТЬ (3 ПРОСТЫХ ШАГА):**

### Шаг 1: Установить зависимости (ОДИН РАЗ)
```bash
npm install
cd api-server && npm install && cd ..
cd horizon-ui && npm install && cd ..
cd electron-launcher && npm install && cd ..
cd admin-panel && npm install && cd ..
```

### Шаг 2: Настроить конфигурацию

#### A) Настроить ЮKassa (для платежей):
Создайте файл `api-server/.env`:
```
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_БОТА
YUKASSA_SHOP_ID=ВАШ_SHOP_ID
YUKASSA_SECRET_KEY=ВАШ_SECRET_KEY
```

#### B) Настроить серверы (IP адреса):
Откройте `api-server/server.js` и найдите:
```javascript
// Получить список серверов
app.get('/api/servers', (req, res) => {
    const servers = [
        {
            id: 'survival',
            name: 'Survival',
            ip: 'survival.horizon-rp.ru',  // ← ИЗМЕНИТЬ НА ВАШ IP
            port: 25565,
            // ...
        },
        {
            id: 'creative',
            name: 'Creative',
            ip: 'creative.horizon-rp.ru',  // ← ИЗМЕНИТЬ НА ВАШ IP
            port: 25565,
            // ...
        }
    ];
    // ...
});
```

### Шаг 3: Запустить всё одной командой!
```bash
npm start
```

**Это запустит:**
- ⚙️ API Server (port 3000)
- 🎨 React UI (port 5173/5174/5175)
- 🖥️ Electron Launcher (автопоиск React)

**Админ-панель (отдельно):**
```bash
cd admin-panel
npm start
```
Откроется на http://localhost:4000

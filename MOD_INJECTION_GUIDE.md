# Руководство по автоматическому инжекту мода

## Обзор

Лаунчер Horizon автоматически инжектит мод `horizon-cosmetics` в Minecraft при запуске игры. Это происходит полностью автоматически, без участия пользователя.

## Как это работает

### 1. Проверка и сборка мода

При нажатии кнопки "ИГРАТЬ" в главном окне лаунчера:

1. **Проверка наличия собранного мода**
   - Проверяется наличие JAR файла мода в директории `cosmetics-mod/build/libs/`
   - Ищется файл с расширением `.jar`, исключая `-sources` и `-dev` версии

2. **Автоматическая сборка (если требуется)**
   - Если мод не найден, автоматически запускается сборка через Gradle Wrapper
   - Используется команда: `gradlew build --no-daemon`
   - Сборка происходит в фоновом режиме с отображением прогресса

### 2. Копирование мода в .minecraft/mods/

После успешной сборки:

1. **Поиск JAR файла мода**
   - Находится собранный JAR файл мода

2. **Копирование в директорию модов Minecraft**
   - Мод копируется в `~/.minecraft/mods/` (Windows: `%APPDATA%/.minecraft/mods/`)
   - Если мод уже существует, он перезаписывается
   - Это гарантирует, что всегда используется последняя версия мода

### 3. Запуск Minecraft

После успешного копирования мода:

1. **Поиск Java**
   - Сначала используется системная Java из `java.home`
   - Если не найдена, используется Java из `JavaRuntimeManager`

2. **Запуск через Fabric Loader (если установлен)**
   - Если установлен Fabric Loader для выбранной версии Minecraft
   - Мод автоматически загружается при запуске Minecraft через Fabric Loader
   - Все моды в `.minecraft/mods/` автоматически загружаются Fabric Loader

3. **Альтернативный запуск (если Fabric Loader не установлен)**
   - Мод все равно копируется в `.minecraft/mods/`
   - Пользователю показывается информационное сообщение
   - Мод будет загружен при следующем запуске Minecraft через стандартный лаунчер с Fabric Loader

## Структура файлов

```
Horizon/
├── launcher-java/
│   └── src/main/java/com/horizon/launcher/
│       ├── minecraft/
│       │   └── GameLauncher.java          # Основной класс для запуска и инжекта мода
│       └── ui/
│           └── MainWindow.java            # Главное окно с кнопкой запуска
│
└── cosmetics-mod/
    ├── build/
    │   └── libs/
    │       └── horizon-cosmetics-1.0.0.jar  # Собранный мод (автоматически)
    ├── build.gradle                         # Конфигурация сборки
    └── gradle.properties                    # Свойства сборки
```

## Пути и директории

### Директория модов Minecraft
- **Windows**: `%APPDATA%\.minecraft\mods\`
- **Linux/Mac**: `~/.minecraft/mods/`

### Директория исходников мода
- **Относительно корня проекта**: `cosmetics-mod/`

### Директория сборки мода
- `cosmetics-mod/build/libs/`

## Требования

### Для автоматической сборки мода:
1. **Gradle Wrapper** должен быть в директории `cosmetics-mod/`
   - Файлы: `gradlew` (Linux/Mac) или `gradlew.bat` (Windows)
   - Если отсутствует, нужно инициализировать Gradle в директории мода

2. **Java 21** для сборки мода
   - Должна быть установлена системная Java 21
   - Или используйте `JavaRuntimeManager` из лаунчера

### Для запуска Minecraft с модом:
1. **Fabric Loader** для выбранной версии Minecraft
   - Должен быть установлен в `~/.minecraft/versions/fabric-loader-<version>/`
   - Можно установить через [Fabric Installer](https://fabricmc.net/use/)

2. **Fabric API** (рекомендуется)
   - Должен быть установлен в `.minecraft/mods/`
   - Скачивается автоматически при использовании Fabric Loader

## Логи и отладка

### Логи лаунчера
- Логи записываются через SLF4J + Logback
- Можно настроить в `logback.xml`

### Логи сборки мода
- Вывод Gradle показывается в логах лаунчера
- Префикс: `[Gradle]`

### Логи Minecraft
- Записываются в `~/.minecraft/logs/horizon-launcher.log`
- Содержат вывод процесса Minecraft

## Устранение проблем

### Мод не собирается
1. Проверьте наличие Gradle Wrapper в `cosmetics-mod/`
2. Убедитесь, что Java 21 установлена и доступна
3. Проверьте логи лаунчера на ошибки сборки

### Мод не копируется
1. Проверьте права доступа к директории `.minecraft/mods/`
2. Убедитесь, что директория существует или может быть создана

### Мод не загружается в Minecraft
1. Убедитесь, что установлен Fabric Loader для выбранной версии Minecraft
2. Проверьте, что мод скопирован в `.minecraft/mods/`
3. Проверьте совместимость версии мода и версии Minecraft
4. Проверьте логи Minecraft на ошибки загрузки мода

### Fabric Loader не установлен
- Установите Fabric Loader через [Fabric Installer](https://fabricmc.net/use/)
- Или запустите Minecraft вручную через стандартный лаунчер с Fabric Loader
- Мод будет автоматически загружен при следующем запуске

## Дополнительная информация

### Автоматическое обновление мода
- При каждом запуске игры мод автоматически собирается (если изменился)
- Последняя версия мода всегда копируется в `.minecraft/mods/`

### Совместимость версий
- Мод собран для Minecraft 1.21
- Проверьте совместимость с выбранной версией Minecraft в лаунчере
- При необходимости обновите версию в `cosmetics-mod/gradle.properties`

## Пример использования

1. **Запуск лаунчера**
   ```bash
   cd launcher-java
   mvn javafx:run
   ```

2. **Вход в систему**
   - Введите логин и пароль
   - При необходимости введите код 2FA из Telegram

3. **Выбор версии и запуск**
   - Выберите версию Minecraft (например, 1.21)
   - Установите объем памяти (например, 4096 МБ)
   - Нажмите кнопку "ИГРАТЬ"

4. **Автоматический процесс**
   - Лаунчер проверяет и собирает мод (если нужно)
   - Копирует мод в `.minecraft/mods/`
   - Запускает Minecraft с модом

## Заключение

Автоматический инжект мода полностью интегрирован в лаунчер и работает прозрачно для пользователя. Мод всегда актуален и готов к использованию при запуске игры.

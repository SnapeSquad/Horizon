# Система авторизации для Horizon Launcher

**Дата:** 2026-01-11  
**Статус:** ✅ Реализована

## Созданные компоненты

### Утилиты
1. ✅ **SessionManager.java** - Менеджер сессий для хранения JWT токенов
2. ✅ **HWIDManager.java** - Менеджер для получения Hardware ID (SHA-256 хеш)
3. ✅ **Toast.java** - Компонент для красивых всплывающих уведомлений

### Сервисы
1. ✅ **AuthService.java** - Сервис авторизации с поддержкой Telegram 2FA
   - `attemptLogin()` - Попытка входа с автоматической обработкой 2FA
   - `verify2FA()` - Проверка 2FA кода
   - Интеграция с HWID через HWIDManager
   - Сохранение JWT токенов через SessionManager

### UI Компоненты
1. ✅ **AuthWindow.java** - Окно авторизации в стиле iOS 26 Liquid Glass
   - Стеклянные панели с эффектом размытия
   - Скругленные углы 20px
   - Градиентные кнопки (от #667eea до #764ba2)
   - Плавные анимации (FadeTransition и TranslateTransition)
   - Автоматическое ограничение поля 2FA на 6 символов
   - Toast уведомления для ошибок

## Реализованные функции

### Авторизация
- ✅ Вход с логином и паролем
- ✅ Автоматическое переключение на форму 2FA при необходимости
- ✅ Проверка 2FA кода (6 символов)
- ✅ Сохранение JWT токенов в SessionManager
- ✅ Интеграция HWID во все запросы авторизации

### UI/UX
- ✅ Стиль iOS 26 Liquid Glass
- ✅ Плавные анимации переключения между формами
- ✅ Градиентные кнопки
- ✅ Стеклянные панели с эффектом размытия
- ✅ Toast уведомления для ошибок:
  - "Неверный пароль"
  - "Код 2FA истек"
  - "HWID заблокирован"
  - "Неверный код 2FA"
  - "Пользователь не найден"

### Безопасность
- ✅ HWID автоматически добавляется в каждый запрос авторизации
- ✅ JWT токены сохраняются в зашифрованном файле
- ✅ Ограничение поля 2FA на 6 символов (только цифры)

## Интеграция с API

### Эндпоинты
- ✅ POST /api/auth/login - Вход с автоматической обработкой 2FA
- ✅ POST /api/auth/verify-2fa - Проверка 2FA кода

### Формат запросов
Все запросы авторизации автоматически включают:
- `username` - Имя пользователя
- `password` - Пароль (для login)
- `code` - Код 2FA (для verify-2fa)
- `hwid` - Hardware ID (SHA-256 хеш)

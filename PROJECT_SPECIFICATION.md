## 📐 АРХИТЕКТУРА ПРОЕКТА

Проект состоит из трех основных компонентов:

1. **Electron Launcher** (`launcher/`) - Первоначальная версия на Electron/Node.js
2. **Java Launcher** (`launcher-java/`) - Миграция на Java/JavaFX (текущая версия)
3. **API Server** (`api-server/`) - Backend на Node.js с Express и SQLite

## 📝 API ДОКУМЕНТАЦИЯ

### Базовый URL: `http://localhost:3000`

### Аутентификация:
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `POST /api/user/2fa/telegram/setup` - Настройка Telegram 2FA
- `POST /api/user/2fa/disable` - Отключение 2FA
- `GET /api/user/2fa/status` - Статус 2FA

### Пользователь:
- `GET /api/user/cosmetics?username=...` - Косметика пользователя
- `POST /api/user/cosmetics/add` - Добавить косметику
- `GET /api/user/currency?username=...` - Баланс валюты
- `GET /api/user/skin?username=...` - Скин пользователя
- `POST /api/user/skin` - Загрузить скин
- `GET /api/user/skin/model?username=...` - Модель скина
- `POST /api/user/skin/model` - Изменить модель

### Косметика:
- `GET /api/cosmetics/available` - Доступная косметика
- `POST /api/user/currency/purchase` - Купить косметику
- `GET /api/cosmetics/mods` - Список модов
- `GET /api/cosmetics/animations` - Анимации косметики
- `POST /api/cosmetics/animations` - Сохранить анимацию

### Форум:
- `GET /api/forum/categories` - Категории
- `GET /api/forum/topics?category_id=...` - Темы
- `POST /api/forum/topics` - Создать тему
- `GET /api/forum/posts?topic_id=...` - Сообщения
- `POST /api/forum/posts` - Создать сообщение
- `POST /api/forum/posts/like` - Лайкнуть сообщение

### Админ:
- `POST /api/admin/currency/give` - Выдать валюту (требуется ADMIN_TOKEN)

### Сервер:
- `GET /api/server/status` - Статус Minecraft сервера
